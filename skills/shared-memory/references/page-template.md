# Page template

For shared memory with no page convention. Write in its language. File name: lowercase kebab-case.

````markdown
# <Topic>

<What a reader learns here, in one or two sentences.>

## Observations

- <fact> (evidence: <PR, ticket, path, or command>; checked: YYYY-MM-DD)

## Hypotheses

- <unverified idea> (reason: <why>)

## Related

- <pages or links>
````

Drop empty sections. Index line: `- [<Topic>](<link>) — <what it tells you>`.
