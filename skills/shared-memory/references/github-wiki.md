# GitHub Wiki storage

Sync and publish as in git.

- Upstream: `https://github.com/OWNER/REPO.wiki.git`. Create the first page in the web UI before cloning.
- Index: `Home.md`, or `_Sidebar.md` if the Wiki uses it.
- `Some-Page.md` is served at `https://github.com/OWNER/REPO/wiki/Some-Page`. Match the existing link style.
- Readership follows the repository's visibility.
- Claude Code in the cloud, including Routines, cannot select a Wiki as a source; use a regular repository there.
