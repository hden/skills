# GitHub Wiki

Use the configured Wiki working directory. Start with `Home.md` if it indexes the pages. Preserve the Wiki's page naming and links. Add or update the entry for a page in `Home.md` or the existing sidebar when it serves as navigation. Verify links using the Wiki's conventions.

Confirm who can read the Wiki before writing. Follow the team's established Git workflow for syncing or publishing changes.

[GitHub Wiki documentation](https://docs.github.com/en/communities/documenting-your-project-with-wikis/adding-or-editing-wiki-pages)
