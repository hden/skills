# kb migrate

Promote team-worthy knowledge from agents' own memories (see agents for their locations) into the KB.

1. Collect sources: paths the user supplies, or the curated memory files of the agents in use. Skip raw transcripts.
2. Keep only findings that are reusable in this project and fit the KB's readership. Drop personal preferences and anything whose audience is unclear.
3. Verify each finding still holds, then merge it into existing pages as in "While working".
4. Publish with `confirm`, whatever the configured mode: the material was written for a narrower audience.
5. Leave the source memories in place unless the user asks to remove them.
6. Report the changed pages and how many findings were skipped, without quoting them.
