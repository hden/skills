# Storage: local directory

A directory without a remote, for a team of one or a KB shared by other means.

- Sync: nothing to do.
- Publish: save the files. If the directory is a Git repository, commit the reviewed changes so history is kept.
- Readership: whoever can read the directory. Check before writing if it is synced elsewhere (e.g. a shared drive).
- Report: the changed paths.
